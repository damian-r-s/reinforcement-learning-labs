# Reinforcement Learning Labs

A collection of reinforcement learning implementations, experiments, and study notes.

## Languages

- **C++** – implementations from scratch to improve systems programming and understand algorithm internals.
- **Python** – implementations using the modern RL ecosystem (NumPy, Gymnasium, PyTorch) for experimentation and comparison.

## Topics

- Multi-Armed Bandits
- Dynamic Programming
- Monte Carlo Methods
- Temporal-Difference Learning
- Deep Q-Networks (DQN)
- Policy Gradient Methods
- PPO
- SAC
